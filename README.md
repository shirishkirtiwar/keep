# Keep

Browser app for sorting photos — and separately, videos — by keep or skip.

**Repo:** [github.com/shirishkirtiwar/keep](https://github.com/shirishkirtiwar/keep) (private)

- **Keep** (swipe right, →, or the Keep button) copies that item into the next round.
- **Skip** (swipe left, ←, or the Skip button) drops it from this pass only.
- Originals are never moved or deleted.
- Export writes a zip when you are sure.

## You do not need Git to use this

Open Keep in Grok (the live preview, or Publish for a `*.grok.me` link). Sort in the browser. No Node, no install.

## If you want the files on your computer

1. Open this GitHub page while logged in as **shirishkirtiwar**.
2. Click the green **Code** button → **Download ZIP**.
3. Unzip the folder.

That is the source. Friends you add as collaborators can do the same.

To let someone else see it: GitHub → **Settings** → **Collaborators**, or change visibility to public.

## How Keep works

1. Choose Photos or Videos.
2. Pick a source (sample walk, files, folder, or Drive).
3. Phone/tablet: swipe. Laptop: Skip far left, Keep far right. Arrow keys: ← skip, → keep, Z undo.
4. When the round is empty, open the next Keep round and sort the smaller set.
5. Export only when you are sure.
